# 8-PageTable

https://1000os.seiya.me/ja/11-page-table

"ページテーブル"は、仮想アドレスと物理アドレスの対応表を指す。
ページテーブルを切り替えれば、同じ仮想アドレスでも異なる物理アドレスにアクセスさせることができる。
カーネルとアプリケーション、アプリケーションごとのメモリ空間を隔離することで、システムの安全性を高めることができる。

1. ページテーブルを実装し、実行してみる。
2. QEMU モニター画面で `stop` コマンドを実行した後、 `satp` レジスタの値を確認してみる。
   - `info registers` コマンドで確認できる。

```
 satp     80080246
```
=> VPN[1]=0x200, VPN[0]=0x0, PPN=0x80246
ページテーブル1段目は (0x80080246 & 0x3FFFFF) * 4KB = 0x80246000 に存在する。
ページテーブル1段目のページ番号は 0x200 = 512 番. 

3. `xp` コマンドで物理メモリをダンプする.
   - `/x` で16進数表示にする.

```
(qemu) xp /x 0x80246000+512*4
0000000080246800: 0x20091c01
```
=> (0x20091c01 >> 10) * 4KB = 0x80247 << 12 = 0x80247000 にページテーブル2段目が存在する.

`/1024x` と書くと 1024 ワード分ダンプできる.

```
...
00000000802477f0: 0x00000000 0x00000000 0x00000000 0x00000000
0000000080247800: 0x200800cf 0x2008040f 0x2008084f 0x20080c0f
...
```
=> 0x80247000+0x800 から値が埋まっている.
    0x800 / 4 = 512 番目のエントリから値が設定されている.
512 << 12 = 0x20000000 が仮想アドレスにおける VPN[1] の値
    => `0x80200000` からカーネル領域がマッピングされていることが分かる.
        この値は `__kernel_base` シンボル (ベースアドレス) と一致する.

4. `info mem` でページテーブル設定情報を確認する.


- `a` : ページにアクセスしたことがある.
- `d` : ページが書き換えられたことがある (dirty).
```
vaddr    paddr            size     attr
-------- ---------------- -------- -------
80200000 0000000080200000 00001000 rwx--ad
80201000 0000000080201000 00001000 rwx----
...
```
